# Atividade 7 - Consulta aos compromissos do calendário

Atividade da disciplina de Programação para Dispositivos Móveis.

**Aluno:** Eric França Arantes dos Santos

**Professor:** Arley

## Descrição

Aplicativo Flutter para consultar os calendários do dispositivo e listar os
compromissos de hoje e dos próximos seis dias.

Para cada compromisso, são apresentados título, calendário, início, fim, local,
descrição e a identificação de evento de dia inteiro.

## Como executar

Com Flutter e Android SDK instalados, conecte um dispositivo Android ou inicie
um emulador e execute:

```bash
flutter pub get
flutter run
```

O aplicativo solicitará acesso ao calendário.

## Verificação

O projeto foi analisado com `flutter analyze`, compilado para Android e testado
em um Samsung Galaxy A31 com Android 12.
